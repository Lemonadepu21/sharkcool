# SharkCool Windows

适用于 Windows 10/11 x64。此版包含实际 Windows HID 与 BLE 后端、独立 Qt 控件窗口，未使用浏览器、WebView、Wine 或官方驱动二进制。

推荐下载 `SharkCool-1.14.0-windows-x64-setup.exe`，双击安装即会创建桌面与开始菜单入口，包含 Qt、C++ 和 .NET 运行库。安装时自动准备 CPU/GPU 温度采集服务与官方签名 PawnIO 驱动，需要一次管理员授权；完成后不需要额外配置或另开监控软件，日常运行与登录自启不需要提权。安装时不会自动开启应用登录自启。

若选便携 ZIP：

1. 将整个 ZIP 解压到固定目录；保留三个组件、Qt DLL 和 plugins 子目录。
2. 双击 `SharkCool.exe`。USB 请使用 USB-IN 数据接口；蓝牙请先在 Windows 设置配对 `BS BRB02 Cooler Pro`，再启动应用。
3. 双击 `Install-Shortcuts.cmd` 创建当前用户桌面与开始菜单快捷方式；无需管理员权限。安装后不要移动应用目录。
4. 首次打开 `SharkCool.exe` 时自动准备温度采集服务，按系统提示完成一次管理员授权；再次打开复用已有服务，发现旧版时自动更新。取消后仍可控制散热器；登录自启不会弹出授权。

概览页显示真实转速，屏幕、灯效可独立切换。固定转速、四档配置、温控曲线编辑、RGB、屏保上传/恢复和设备启动设置沿用 Linux 版。首次连接与重新连接只读取设备状态，不自动覆盖四档转速；命令失败不自动重放。

关闭窗口后驻留托盘；再次打开只激活同一实例。托盘右键可打开窗口、切换登录自启、退出应用与后台控制服务。登录自启也可在应用「设置」开启，登录后直接驻留托盘；解压与创建快捷方式不会自动开启。`Stop-SharkCool.cmd` 保留为备用停止入口。

首版用户反馈设备控制与 GPU 温度正常，CPU 温度无法读取。新版重点改进自动初始化、传感器兼容性与采集效率；CI 检查编译、可信管道读取、首次启动初始化、重复启动、打包后窗口、安装与卸载。新增采集路径仍需真机确认。

Windows 系统信息可读取 CPU/GPU 温度与使用率、内存、系统盘、时钟。统一采集服务自动识别可用的 AMD / Intel / NVIDIA GPU，NVIDIA 保留 `nvidia-smi` 后备路径，无需手动选择采集源。GPU 优先读取核心温度，不以显存或热点温度代替。CPU 优先使用封装温度，缺少封装传感器时取可用核心温度的最大值。后台直接通过已验证服务身份的本地管道获取数据，不再每次启动 .NET 采集进程；短时间内的重复请求共用采样，退出应用后不持续轮询。CPU 型号不受组件支持、驱动未就绪或无法读取时显示「—」，不填充虚假温度；实际硬件兼容性仍待真机验证。硬件未提供传感器时相应指标不可用。主机音频/输入采集和只读 BLE 链路日志暂不支持。完整关闭风扇尚未实现；屏幕/灯效关闭保持连接。

卸载应用会移除 `SharkCoolSensors` 服务。PawnIO 可能被其他硬件监控软件共用，卸载时保留；需要时可在 Windows「已安装的应用」中单独卸载 PawnIO。已有兼容版本不会被覆盖；若旧版本低于 2.0，请先更新 PawnIO。

官方控制软件若同时访问设备可能争抢响应，请关闭后再用本应用。默认监听仅 `127.0.0.1:17865`，不开放局域网。日志位于 `%LOCALAPPDATA%\sharkcool\service.log` 和 `window.log`；备份在用户缓存目录，未写入应用安装目录。

命令行可用 `sharkcool-service.exe doctor`、`version`、`gui --transport usb`、`gui --transport ble --address AA:BB:CC:DD:EE:FF`。GUI 子系统程序在脚本中应使用 `Start-Process -Wait` 或重定向输出。完整命令与参数请运行 `sharkcool-service.exe help`。
